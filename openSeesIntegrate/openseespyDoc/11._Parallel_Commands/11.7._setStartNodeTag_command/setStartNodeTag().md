# setStartNodeTag()

# 11.7. setStartNodeTag command

setStartNodeTag(*ndtag*)
:   Set the starting node tag for the [mesh command](mesh.html).
    The purpose of this command is to control
    the node tags generated by the [mesh command](mesh.html). Some
    nodes are shared by processors, which must
    have same tags. Nodes which are unique to
    a processor must have uniques tags across
    all processors.

    > |  |  |
    > | --- | --- |
    > | `ndtag` ([int](https://docs.python.org/3/library/functions.html#int)) | starting node tag for the next call of [mesh command](mesh.html) |
