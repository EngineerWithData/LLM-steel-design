# sensLambda()

# 9.12. sensLambda command

sensLambda(*patternTag*, *paramTag*)
:   Returns the current load factor sensitivity to a parameter in a load pattern.

    |  |  |
    | --- | --- |
    | `patternTag` ([int](https://docs.python.org/3/library/functions.html#int)) | load pattern tag |
    | `paramTag` ([int](https://docs.python.org/3/library/functions.html#int)) | parameter tag |
