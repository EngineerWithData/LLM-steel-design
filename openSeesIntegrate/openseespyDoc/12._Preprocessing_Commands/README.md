# 12. Preprocessing Commands

The [mesh command](mesh.html) and [remesh command](remesh.html) should be
called as

```python
import openseespy.opensees as ops
ops.mesh()
ops.remesh()
```

The [DiscretizeMember command](DiscretizeMember.html) should be called as

```python
import openseespy.preprocessing.DiscretizeMember as opsdm

opsdm.DiscretizeMember()
```
